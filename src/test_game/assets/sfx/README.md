# Foxglove SFX runtime files

Place the **game-ready OGG category folders** from Foxglove SFX v0.1 here:

- `ambience/`
- `combat/`
- `magic/`
- `reactions/`
- `ui/`

The cue registry one directory above (`../sfx_cues.json`) already points at
those paths. The WAV masters, audition previews, generator script, QA CSV, and
hash manifests are development/source materials and are not needed by the game.

Example final path:

`src/test_game/assets/sfx/ui/confirm_01.ogg`
